# NuWa
ini adalah app terbuka untuk semua orang yang berkenan menulis menggunakan aksara jawa.
Halaman ini masih bersifata dikembangkan jadi bila ada kesalahan dalam penulisan kode atau simbol atau apa pun mohon untuk memberitahu lewat komentar.
Tujuan dari pembuatan tool ini semata untuk melestarikan budaya yang semakin hari semakin memudar.
